Contenido

Etiqueta "p"
Es la etiqueta que se usa para definir el contenido principal de un documento HTML.
Etiqueta "hr"
Define una línea horizontal en un documento HTML.
Etiqueta "pre"
Define texto preformateado en un documento HTML.
Etiqueta "blockquote"
Define una sección que es citada de otra fuente.
Etiqueta "div"
Es la etiqueta que se usa para definir un área o división en un documento HTML.
Etiqueta "dl"
Es la etiqueta que se usa para definir un elemento en línea en un documento HTML.

Listas

Atributo "type" y "start"

  1. El atributo "type" establece el formato de numeracion
  2. El atributo "start" establece el valor inicial de la numeracion
  3. 1: Números arábigos estándar (1, 2, 3...) — Es el valor predeterminado.
  4. a: Letras minúsculas del alfabeto (a, b, c...).
  5. A: Letras mayúsculas del alfabeto (A, B, C...).
  6. i: Números romanos en minúscula (i, ii, iii...).
  7. I: Números romanos en mayúscula (I, II, III...).

Atributo "reversed"

  1. El atributo "reversed" establece el orden inverso de la numeracion
  2. Primer elemento = 3
  3. Segundo elemento = 2
  4. Tercer elemento = 1

Texto

La etiqueta em da énfasis a una palabra; por ejemplo, “es muy importante”.

La etiqueta strong indica que una parte del texto tiene gran importancia: ¡Atención!

La etiqueta small se usa para notas o aclaraciones secundarias: Consulta las condiciones.

La etiqueta s tacha información que ya no es correcta o relevante: Precio anterior: 20 €.

La etiqueta cite señala el título de una obra: La casa de Bernarda Alba.

La etiqueta q encierra una cita breve dentro de una oración: Cervantes escribió En un lugar de la Mancha.

La etiqueta dfn marca un término cuando se explica su significado: HTML es un lenguaje de marcado.

La etiqueta abbr muestra una abreviatura; su atributo title indica el significado: ONU.

La etiqueta time representa una fecha u hora que los navegadores pueden interpretar: 14 de octubre de 2026.

La etiqueta code identifica código informático, por ejemplo: print("Hola").

La etiqueta var representa una variable en una expresión: x + 2 = 5.

La etiqueta samp muestra un resultado producido por un programa: Proceso completado.

La etiqueta kbd representa una tecla o combinación que debe pulsarse: Ctrl + C.

La etiqueta sub coloca texto por debajo de la línea, como el 2 en la fórmula del agua: H2O.

La etiqueta sup coloca texto por encima de la línea, como el 2 en una potencia: x2.

La etiqueta i diferencia una palabra por convención, como un término en otro idioma: carpe diem.

La etiqueta b resalta visualmente una palabra sin indicar que sea más importante: Nuevo.

La etiqueta u subraya un fragmento para señalar una anotación: palabra mal escrita.

La etiqueta mark destaca una parte del texto, como una coincidencia: Resultado encontrado.

La etiqueta span agrupa una parte del texto en línea para poder darle estilo: esta palabra.

La etiqueta br introduce un salto de línea sin empezar otro párrafo: primera línea
segunda línea.

La etiqueta wbr indica un punto donde una palabra larga puede dividirse si falta espacio: superextraordinario.

Caracteres

Para mostrar una etiqueta se usaron &lt; y &gt;: <p>.

Entidad usada para mostrar el euro: &euro; → €.

Código decimal usado para mostrar el euro: &#8364; → €.

Código hexadecimal usado para mostrar el euro: &#x20AC; → €.

Para añadir varios espacios se usó &nbsp;: uno   dos.
